# POUR 마케팅 허브

> 일을 맡길 팀원을 고르세요. 팀원 노트에 **받는 것 → 주는 것 → Claude 프롬프트**가 있고, 결과물은 `03 작업`에 쌓입니다.

## 기준: [[모카|모카 제품마스터]]
모든 제품 정보는 `01 제품마스터`의 제품 카드에 있습니다. 팀원은 제품 카드를 받아서 일합니다.

```dataview
TABLE WITHOUT ID length(rows) AS "제품 수"
FROM "01 제품마스터" WHERE 유형 = "제품"
GROUP BY true
```

```dataview
TABLE WITHOUT ID 채널, length(rows) AS "제품 수"
FROM "01 제품마스터" WHERE 유형 = "제품"
GROUP BY 채널
```

## 진행 중인 작업
```dataview
TABLE 담당, 제품, 상태, 마감
FROM "03 작업" WHERE 상태 != "완료"
SORT 마감 ASC
```

## 최근 완료
```dataview

FROM "03 작업" WHERE 상태 = "완료"
SORT file.mtime DESC LIMIT 10
```
