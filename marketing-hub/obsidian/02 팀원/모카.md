# 모카 · 제품마스터
> 본부에서 파는 모든 제품의 가격, 옵션, 상세페이지, 소스 카드는 저한테 물어보세요.

모카는 사람이 아니라 **`01 제품마스터` 폴더 자체**입니다. 제품마다 노트 1개(제품 카드)를 만듭니다.

## 새 제품 등록
1. `01 제품마스터` 폴더에서 새 노트 → 템플릿 **제품 카드** 삽입
2. 맨 위 속성(가격·채널·옵션 등)을 채우고, 본문 섹션을 채움
3. 다른 팀원 작업 노트에서 `[[제품명]]`으로 연결

## 전체 제품
```dataview
TABLE 채널, 판매가, 프로모션가, 카테고리, 상세카드
FROM "01 제품마스터" WHERE 유형 = "제품"
SORT 카테고리 ASC, file.name ASC
```

## 상세 카드 미완성
```dataview
LIST FROM "01 제품마스터" WHERE 유형 = "제품" AND 상세카드 != "완료"
```
