# 처음 읽기

이 볼트는 공유받은 **POUR 마케팅 허브**(Claude 페이지)의 구조를 Obsidian으로 옮긴 것입니다.

## 폴더
| 폴더 | 원래 허브에서 | 내용 |
|---|---|---|
| `00 허브.md` | 첫 화면 | 팀원 목록 + 진행 중 작업 대시보드 |
| `01 제품마스터` | 모카 | 제품 1개 = 노트 1개 (제품 카드) |
| `02 팀원` | 11개 자리 | 받는 것 / 주는 것 / Claude 프롬프트 |
| `03 작업` | 각 작업실 결과 | 맡긴 일 1건 = 노트 1개 |
| `99 템플릿` | – | 제품 카드, 작업 요청 템플릿 |

## 설정 (1번만)
1. Obsidian → **볼트 폴더 열기** → 이 폴더 선택
2. 설정 → 커뮤니티 플러그인 → **Dataview** 설치·활성화 (허브 표가 이걸로 그려짐)
3. 설정 → 핵심 플러그인 → **템플릿** 켜기 → 템플릿 폴더 위치: `99 템플릿` (미리 설정돼 있음)

## 쓰는 흐름
1. `01 제품마스터`에 제품 카드 만들기 (템플릿: 제품 카드)
2. `03 작업`에 작업 노트 만들기 (템플릿: 작업 요청) → `담당`, `제품` 연결
3. 담당 팀원 노트의 **프롬프트**를 복사 → Claude에 붙여넣고 제품 카드 내용과 입력 자료를 이어 붙이기
4. 결과를 작업 노트 `결과물`에 붙여넣고, `상태`를 `완료`로

예시 노트 2개(`예시 - …`)는 확인 후 지워도 됩니다.

## 대시보드 숫자 받기 (판매·광고·재고)
1. 마케팅 허브 대시보드(https://pour-construction-form.pages.dev/marketing-hub/) → **설정 › 옵시디언** → 볼트 이름 확인 → **[허브에 연결]** 한 번 (이 볼트를 새로 받았다면 이미 연결돼 있으니 생략)
2. 그 뒤로는 **요약 › [옵시디언으로 보내기]** → 옵시디언이 열리고 `05 오늘 숫자` 노트가 새 숫자로 바뀜 → `00 허브` 맨 아래에 보임
- `05 오늘 숫자`는 보낼 때마다 통째로 바뀝니다. 메모는 다른 노트에 쓰세요.
