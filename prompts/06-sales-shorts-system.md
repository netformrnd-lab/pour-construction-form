# 06. 상품판매 숏폼 제작 시스템 (POUR스토어 · GROHOME)

> 기준일 2026.10.02
> 근거 자료: ① 「2026 AI 영상 제작 최적 스택」(2026.09.28) ② 「AI 프롬프트 실무 바이블」(2026.10.01) ③ pour-shorts-v2 스킬
> 목적: 소비자가 가진 고민을 정확히 짚어 **"이거 사야겠다"** 를 만드는 9:16 판매 숏폼을, 사용자는 **자료만 넘기고** AI가 기획·생성·편집 지시까지 끝내는 구조.

---

## 0. 일하는 방식 — 사용자는 "자료 전달"만

```
[사용자]  상품링크 + 썸네일 + 다른 각도샷 전달
   ↓
[AI]      상세페이지 분석 → 소비자 니즈 진단 → 기획안(컷표·대본) 작성
   ↓      부족한 자료가 있으면 "자료 요청서"로 딱 필요한 것만 요청
[사용자]  요청받은 자료만 추가 전달 (없으면 "없음"이라고만 답)
   ↓
[AI]      키프레임 → 영상 생성 → 나레이션 → 자막 → 완성 mp4 + 캡컷 소스
   ↓
[사용자]  승인 2번만: ① 기획안·목소리  ② 첫 AI 컷
```

- 사용자에게 **프롬프트를 쓰게 하거나 툴을 조작하게 하지 않는다.**
- 요청서에는 항상 **"왜 필요한지 + 없으면 어떻게 대체하는지"** 를 같이 쓴다. 없다고 하면 대체안으로 바로 진행한다.
- 한 번에 묻는 자료는 최대 3개. 폰으로 바로 찍거나 캡처해서 보낼 수 있는 것만.

## 1. 자료 체계

### 1-1. 기본 3종 (매번 필수)

| # | 자료 | 용도 | 기준 |
|---|------|------|------|
| ① | 상품 링크 | 상품명·가격·구성·용도·리뷰 분석, 마지막 구매 안내 | 스토어 상세페이지 URL |
| ② | 썸네일 | **Hero Frame**(제품 형상·라벨·색 고정 원본) | 흰 배경 정면, 라벨이 읽히는 원본 해상도 |
| ③ | 다른 각도샷 | 회전·측면·뚜껑·구성품 컷의 기준 (AI가 라벨을 새로 그리지 않게) | 측면·45도·후면·구성품 펼침 중 2~4장 |

### 1-2. 추가 요청 목록 (AI가 필요할 때만 요청)

| 코드 | 자료 | 요청 조건 | 없을 때 대체안 |
|------|------|----------|--------------|
| R1 | 상세페이지 캡처 | 상세 설명이 이미지라 글자를 못 읽을 때 | 링크 텍스트·옵션명만으로 기획 (수치 표현은 빼고) |
| R2 | 시공/사용 실사 영상·사진 | 실제 바르는·붙이는 장면이 필요할 때 (POUR 제품 사용 장면은 AI 생성 금지) | 원리 설명 AI 컷 + 제품 실사 줌으로 구성 |
| R3 | 시공 전·후 실사 사진 | "이렇게 바뀐다" 증거 컷 | 전후 컷 없이 원리·사용법 중심 구성 |
| R4 | 시험성적서·인증서 | 화면에 수치를 넣을 때 | 수치 없이 "잡아당겨도 버티는 힘" 등 쉬운 말로만 |
| R5 | 실제 고객 리뷰 캡처 | 후기 컷을 넣을 때 (AI 가짜 후기 금지) | 후기 컷 생략, "자주 묻는 질문" 형식으로 대체 |
| R6 | 현재 프로모션 | 할인·쿠폰·사은품을 마지막에 넣을 때 | 혜택 언급 없이 구매 경로만 안내 |
| R7 | 레퍼런스 숏폼 링크 | 원하는 톤·편집 스타일이 따로 있을 때 | 이 문서 기본 구조로 진행 |
| R8 | 목소리 선택 | 기획안 승인 때 (샘플 2개 들려드림) | 차분한 남성/여성 중 브랜드 기본값 |
| R9 | 영상 속 손·작업자 촬영 | 사용 장면을 직접 찍을 수 있을 때 (촬영 가이드 같이 드림) | R2 대체안과 동일 |

## 2. 구매욕구를 만드는 숏폼 구조 (기본 30초)

소비자 심리 순서: **"어? 우리집 얘기네" → "이대로 두면 손해" → "생각보다 쉽네" → "진짜네" → "지금 사자"**

| 구간 | 시간 | 역할 | 화면 | 나레이션 예 |
|------|------|------|------|-----------|
| ① 후크 | 0~3초 | 문제를 **첫 화면에** 보여줌. 질문·반전형 | 실사 문제 장면(누수 자국·곰팡이·들뜬 바닥) | "베란다 바닥, 또 물 고였죠?" |
| ② 공감·손실 | 3~8초 | 방치하면 커지는 손해(비용·민원·재시공) | 원리 AI 컷(물이 스며드는 단면) | "그냥 두면, 아랫집까지 번지거든요." |
| ③ 기존 방식 한계 | 8~13초 | 왜 지난번엔 실패했는지 | 원리 AI 컷(갈라지는 기존 도막) | "실리콘만 덧바르면 금방 다시 갈라져요." |
| ④ 해결 원리 | 13~19초 | 이 제품이 **무엇이 다른지** 기능으로 | 원리 AI 컷 + 제품 Hero Frame | "시트 자체가 방수층이라, 물이 고여도 버텨요." |
| ⑤ 쉬움 증명 | 19~25초 | "나도 할 수 있다" — 단계 수·시간 | 실사 사용 장면(R2/R9) | "바르고, 붙이고, 덮으면 끝이에요." |
| ⑥ 구매 안내 | 25~30초 | 구성·혜택·구매 경로 | 실사 제품 각도샷 회전 + 링크 안내 | "필요한 것만 한 박스에. 프로필 링크에서 확인하세요." |

### 니즈 진단 (기획 전 AI가 먼저 정리)
- **누가**: 셀프 보수 수요자 / 소규모 시공업체 / 실거주자 중 1명으로 좁힌다.
- **언제 사나**: 장마 전, 누수 발견 직후, 이사·입주 전 등 구매 순간.
- **무엇이 두렵나**: 실패해서 더 망가짐 / 업체 부르면 비쌈 / 어떤 걸 사야 할지 모름.
- **결정 한 방**: 패키지 하나로 끝, 쉬운 단계, 실제 결과.
- 상세페이지·리뷰에서 반복되는 고민 1개만 주제로 고른다. (한 편 = 문제 1개)

## 3. 제작 스택 (최적 스택 PPT의 "B. 제품 정확도 광고" 기준)

```
기획(Claude) → Hero Frame 잠금(썸네일·각도샷) → I2V 엔진 라우팅 → 카메라 연출(Higgsfield) → 부분 수정 → 음성 → 편집
```

| 샷 성격 | 엔진 | 비고 |
|--------|------|------|
| 제품 형상·라벨이 보이는 컷 | 실사 각도샷 → 카메라 무빙만(줌·팬·회전) | 라벨·용기 비율을 AI가 다시 그리지 않게 |
| 원리 설명(단면·물 흐름) | Higgsfield 경유 I2V 상위 엔진 (H3 / Seedance / Kling 중 사용 가능 모델) | 4~8초, 카메라 무빙 1개 |
| 실사감 필요한 건축·야외 | Veo 계열 | 물·재질 물리 |
| 실패 컷 | 전체 재생성 대신 부분 수정 | 오류 1개 = 수정 / 3개 이상 = 재생성 |
| 운영 원칙 | Draft(저해상도·짧게) → Select(2~3개) → Hero(최종) → Repair | 크레딧 절약 |

## 4. 프롬프트 규칙 (실무 바이블 기준)

1. **7요소로 쓴다**: 피사체 → 행동 → 장면 → 카메라 → 조명 → 스타일 → 제약(LOCK).
2. **편집 프롬프트는 "유지 → 변경 → 분위기"** 순. 제품 라벨 유지 문장을 맨 앞에.
3. **부정어 남발 금지**: "Do NOT…" 나열 대신 긍정형 고정 문장 + 네거티브 칸에 명사 3~5개.
4. **컷은 4~8초**, 한 컷에 동작 1~2개·카메라 무빙 1개.
5. **AI 티 제거**: 과한 조명·매끈한 표면·정돈된 배경 대신 자연광·실제 질감·약간 불완전한 구도.
6. **글자는 AI에 그리지 않는다**: 자막·가격·제품명은 편집 단계에서 얹는다.
7. "4k, 8k, masterpiece" 같은 품질 단어 대신 렌즈·조명·질감을 구체적으로.
8. 시각 묘사는 영어, 대사·자막은 한국어 원문 따옴표.

## 5. 금지·표시 규칙 (반드시)

- **POUR 제품·시공 장면은 AI로 그리지 않는다.** 실사만. AI 컷은 원리 설명용, 전체의 40~60% 이하.
- **가짜 후기·가짜 사용 경험 금지**: AI 인물이 "제가 써봤는데요" 하는 대본 금지. AI 가상인물이 추천하면 화면에 "가상인물" 지속 표시(공정위 추천·보증 지침).
- **전후 결과·성능을 AI 이미지로 만들지 않는다** (표시광고법). 연출 컷은 원리 설명으로만.
- 수치는 시험성적서(R4)에 있는 것만. 금지 표현: 반영구, 업계 1위, 실리콘 대비 10배, 방수 확실, 건설신기술 1026호.
- 실존 인물·연예인 닮은꼴·유명 음원·실존 브랜드 스타일 모방 금지.
- 유튜브 업로드 시 사실적 합성 장면이 있으면 "변경·합성 콘텐츠" 항목 체크.
- 도구가 넣은 워터마크·메타데이터(C2PA·SynthID) 임의 제거 금지.

## 7. 자료 요청 메시지 템플릿 (AI → 사용자)

```
📦 [상품명] 숏폼 — 자료 요청 (n개)

1) [자료명]
   왜: [한 줄 이유]
   방법: [폰으로 이렇게 찍기/캡처하기]
   없으면: [대체안] → "없음"이라고만 답해주세요.

※ 이것만 받으면 바로 기획안 드립니다.
```

### 촬영 가이드 (R2·R9 요청 시 함께 전달)
- 세로로, 폰 고정(삼각대·벽에 기대기), 5~10초씩 끊어서.
- 손 + 제품 + 작업면이 한 화면에. 라벨이 보이게 한 컷은 따로.
- 자연광(창가·야외 그늘), 줌 쓰지 말고 가까이 가서.
- 단계별로: 준비 → 바르기/붙이기 → 마무리 → 완성면.
