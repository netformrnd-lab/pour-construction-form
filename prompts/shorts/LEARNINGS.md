# 숏폼 제작 학습 노트 — 완성본 5편 프로그램

> **목적**: Claude와 함께 완성본 5편을 만들면서 나온 모든 피드백·기법·실수를 쌓고,
> 5편이 끝나면 이 노트를 바탕으로 **숏폼 스튜디오 대시보드(프롬프트·검사·템플릿)와 제작 도구를 고도화**해
> 사용자가 대시보드에서 **혼자서도** 같은 품질로 만들 수 있게 한다.

## 편별 회고 (완성될 때마다 추가)
### #1 옥상배관방수트랩
- **잘 된 것**: 건축해부도 스타일 단면 + 제품 실물 참조 AI 컷, 3단 거름(밖·안·연장시트) 구조 설명, 서준 목소리, 범용 build_short.py로 설정만 바꿔 재편집
- **오래 걸린 것 / 되돌아간 것**: 목소리(영어 프리셋→복제→서준, 3번 교체), 길이 35→91초로 증가, 대사 수정 후 화면 부족(철근 컷 늘림)
- **다음 편에 바로 적용**: 대본 확정 전에 목소리 1문장 샘플 / 대사 길이에 맞춰 장면 수를 먼저 계산(컷당 화면 5초 이하) / 자막 규칙은 대본 단계에서 적용
- **v14**: 대사가 길어 화면이 모자란 컷은 "원리 장면 1개를 10초로 만들어 앞·뒤 구간을 두 컷에 나눠 쓰기"로 해결 (6번 끝=앞 5초, 7번=뒤 5초). 남은 늘림: 8번 밖에서 거름 ×1.54, 11번 ×1.2
- **도구로 만들 것(고도화 후보)**: 대사 메모장 → 자막 자동 분할(15자·강조 1개) / 화면 부족 컷 자동 경고(클립 길이 < 대사 길이) / 캡컷 zip 분할 업로드
