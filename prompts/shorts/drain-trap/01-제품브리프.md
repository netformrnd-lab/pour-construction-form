## 1. 확인된 사실 (제안서·제품 사진 기준)
- 구성: **거름망 덮개 → 배수통 지지대 → 배수통 → 특수섬유시트** 를 기존 **PVC 배관**에 끼워 설치 (분해도 ref-03)
- 마감: **코트재 + 복합시트**로 바닥과 배수통 사이를 덮어 틈새 누수를 막음
- 기능 ① 배관과 콘크리트 사이 **틈새로 새는 물 억제**
- 기능 ② 거름망 덮개가 **낙엽·먼지를 걸러** 배관 막힘·역류 방지
- 기능 ③ 덮개와 지지대 두께 차이로 생긴 단차 사이로 **물길이 생겨 배수 원활**
- 설치: **비파괴**(기존 구조물 안 깸), 결합식 간편 설치
- 옵션(가격표 기준): 100(직경 75mm 배관용) 시트 포함 / 시트 미포함, 50(직경 45mm) 시트 포함, 연장시트100 별매
- 썸네일 구성: 트랩 + 코트재 통 + 시트 롤 (ref-01)
- 상세 별점: ★4.8/5, 리뷰 9개 (캡처 화면 기준)

## 2. 판매자 주장 (영상에서는 표현을 바꿔서만 사용)
- "물 부식 걱정 끝!", "물 부식 없는 특수소재로 오랜 시간 사용" → 영상: "물에 강한 소재" 수준으로만
- "반영구적 내구성" → **사용 금지** (금지 표현)

## 4. 소비자 니즈 진단
- **누가**: 옥상 있는 단독·다가구·상가 건물주, 소규모 시공업체
- **언제 사나**: 비 온 뒤 배수구 주변 물고임·천장 얼룩 발견 직후, 장마 전 점검
- **두려움**: "어디서 새는지 모르겠다", "실리콘 발랐는데 또 샌다", "업체 부르면 옥상 전체 공사하자고 할까 봐"
- **결정 한 방**: 배수구 하나만 콕 집어 해결 + 배관에 끼우는 간편 설치 + 낙엽 막힘까지 한 번에
- **이번 편 주제(1개)**: "배수구 물은 배관이 아니라 **배관 옆 틈새**로 샌다"
