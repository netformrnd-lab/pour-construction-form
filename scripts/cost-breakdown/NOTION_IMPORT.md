# 분해원가 가져오기 — 노션 · 줄 목록 (2026-11-25)

두 길 모두 **같은 엔진**(한 줄 = 품목 1개의 구성요소 1개 × 업체 1곳)과 **같은 연결 화면**을 씁니다.

| | 노션 (송희님 '구매 관리') | 줄 목록 (AI 소싱 팀장 표) |
|---|---|---|
| 누가·언제 | Aside · 매일 19:00 | 사람 · 필요할 때 |
| 어디서 | `window.costImport.applyNotion(payload)` | 도구줄 [📋 줄 목록 올리기] (xlsx · CSV UTF-8) · 또는 `window.costImport.applyLines(2차원 배열, {dry})` |
| 덮어쓰기 | 노션이 원본인 값은 매번 새 값 | 칸에 값이 있으면 덮어씀 · 빈 칸은 그대로 |
| 기록 | `cost-names/_notion.runs` '노션 동기화' | 같은 자리 '줄 목록 올리기 ○줄' |

**권장: Aside 는 `pourstore-cost.html` 을 바로 엽니다**(같은 로그인 · 1MB 대시보드를 안 기다림). 둘 다 마스터만.

```js
for (let i = 0; i < 60 && !(window.costImport && window.costImport.ready()); i++) await new Promise((r) => setTimeout(r, 500));
const r = await window.costImport.applyNotion(payload);
// r = { added, updated, unchanged, deleted, unmatched: [...], errors: [...] }
```

## 1. 노션 payload (노션 '구매 관리(송희)' 표 → 이 모양)

```js
{ source: "notion", syncedAt: "2026-11-25T19:00:00+09:00", partial: false,   // partial true = 일부만 보냄('노션에서 삭제됨' 표시 안 함)
  suppliers: [{ notionId, name, region: "국내" | "해외", type, payTerms, moveBy, quality, onTime, moq, moqUnit, leadTime, items, note }],   // 공급사 표 (유형·결제 조건·이동비 부담·점수는 선택 — 업체 칸에 보임)
  quotes: [{ notionId, supplierNotionId, title, quoteNo, quoteDate, validUntil, currency, vat, leadTime, status, adopted, notionUrl,   // 견적서 표 1행
             files: [{ name, notionUrl, url }], originUrl,   // 파일 이름 + 노션 페이지 주소 + url(노션 파일 임시 주소 · 1시간) → 서버가 받아 파일 보관(KV)에 복사 후 📎 연결 · 원본 링크(url)
             lines: [{ notionId, title, product: { name, code?, spec? }, noteKind, unitPrice, currency, qty, unit, moq, vat, leadTime, adopted, note, supplierItemName?, supplierItemNo? }] }] }   // 견적 품목 표 행 · 업체 품명·품번(선택)
```

- **노션 파일 복사**(2026-11-25 KV): `files[].url` 이 노션 파일 서버 주소면 서버(`/api/cost-files/notion-copy`)가 직접 받아 보관 → 견적서 📎 에 '노션 · 보관'으로 [미리보기]·[내려받기] · 임시 주소는 저장 안 함 · 다음 동기화 때 같은 파일은 다시 안 받음 · 결과 `r.files` · 따로 1개만: `window.costImport.copyNotionFile({ quoteNotionId, name, url })` → `{ fileId, size, dedup }` · 자세히 QUOTE_FILES.md
- 견적 품목이 없는 견적서 = 견적서 자체(단가·수량·단위)를 한 줄로 넘김 (`lines` 를 비우면 화면이 견적서 값으로 한 줄을 만듦)
- 값은 노션 선택지 글자 그대로: 통화 KRW/USD/CNY · 부가세 'V+ 포함'→V+ · 'V- 별도'→V- · 'V? 확인 필요'→V? · 리드타임·납기(영업일) = 숫자 그대로(영업일 · '2주'·'10일' 같은 글자도 숫자로 바꿈 · 못 읽으면 글자 그대로 = 일정 '확인 필요') → 일정 탭 계산 · 단위(개/장/롤/팩/세트/kg/L/EA/건/회/CBM)는 표시만
- `status`(받음·검토 중/채택/보류/탈락) · `adopted`(채택 여부 체크) — 줄의 `adopted` 가 있으면 그 값
  - **탈락** = 업체 비교엔 보이되 회색 · '최저'·'모두 최저가' 후보에서 빠짐
  - **채택** = '채택' 꼬리표 · 그 구성요소에 업체가 **처음** 들어올 때만 적용 업체로 (그 뒤엔 대시보드에서 고른 적용 업체가 먼저)
- `noteKind`(노션 '구분'): 본품 → 구성요소 줄(처음엔 '연결 필요') · 1회 비용·시험 → 구분 '1회 비용'(1회) · 물류·통관 → '수입 물류'(1회) · 샘플 → 원가에 안 넣고 카드에 '샘플'로만
- 노션 '제품' 관계는 1팀 제품 표라 가격정책표와 이름이 달라 **처음엔 대부분 '연결 필요'** → 연결 화면에서 '이 줄 = 이 품목의 이 구성요소(구분)'를 한 번 고르면 기억:
  같은 줄(노션 id) + **같은 업체·같은 제목**의 다음 견적 줄도 자동 · 노션 쪽 칸은 안 바꿔도 됨

## 2. 줄 목록 (xlsx · CSV UTF-8 · 첫 줄 = 칸 이름 · 이 순서·이 이름)

`자체상품코드 | 품목 | 규격 | 생산 방식 | 국내·수입 | 구분 | 구성요소 | 무엇에 쓰는지 | 업체 | 업체 순위(A 주/B 서브/C) | 업체 품명 | 업체 품번 | 단가 | 통화(KRW/USD/CNY) | 환율 | 부가세(V+/V-/V?) | 개당/1회 | 개당 사용량·1회 횟수 | 구매 수량 | MOQ | 리드타임 | 날짜 | 견적 유효기간 | 생산 수량 | 출처 | 출처 링크 | 상태(확정/임시/확인 필요) | 메모`

- '리드타임' = 영업일 숫자 (글자 '2주'·'10일'도 숫자로 바꿈) · 일정 탭 원자재 입고·인쇄 기간·생산 기간에 씀
- **업체 품명·업체 품번**(2026-11-25 송희님 '좋아'): 그 업체가 부르는 이름·번호(알리바바 주문번호·모델 등) → `cost-names.vprod[줄][업체]` (업체 실명과 같은 규칙 = 마스터·경영 열람만 · 부마스터·부마스터 엑셀엔 안 나옴) · 분해원가 찾기에 걸림 · 노션 = 줄의 `supplierItemName`·`supplierItemNo`(있으면 노션 값) · 줄 목록 = 칸에 값이 있을 때만
- 양식: 도구줄 [줄 목록 양식 받기] (xlsx · 설명 시트 포함) · 올리기 화면에서 CSV 양식도
- 올리기 전 **미리 보기**(새 카드 · 바뀌는 줄 · 그대로 · 연결 필요 · 오류 + 줄마다 결과) → [적용]
- 같은 품목·구분·구성요소·업체 줄 = 덮어쓰기(새로 안 만듦) · 업체 순위 = A/B/C 자리 · 구성요소에 업체가 처음 들어오면 'A'를 적용 업체로
- 외화 = '환율' 칸으로 원화(비면 그 줄 '확인 필요') · '생산 수량'·'생산 방식'·'국내·수입' 칸에 값이 있으면 카드에 · 구매 수량(없으면 MOQ)으로 첫 생산 남는 비용 · '출처 링크' = 견적서 칸(📎) 링크
- 품목을 못 찾으면 '연결 필요' — 연결 화면에서 카드 · 가격표 제품 · **＋ 새 카드**(출시 전 품목) 중 고름 → 같은 품목의 다른 줄도 같이 붙음 · 기억
- 노션에서 온 업체 칸은 줄 목록으로 안 바뀜(오류로 알려 줌 — 노션에서 고침)

## 3. 둘 다 같은 규칙

| 무엇 | 어떻게 |
|---|---|
| 품목 찾기 | 기억(줄 → 품목·구성요소) → 자체상품코드 → 제품명+규격 → 카드 품목+규격 → 못 찾으면 연결 필요 |
| 가격표엔 있는데 카드가 없음 | 새 카드 (생산 방식 = 공급업체가 넷폼이면 자체생산, 그 밖 국내 OEM) |
| 업체 칸 | (노션) 노션 줄 id → 같은 업체 이름 칸 → 빈 칸(기본 A) → 새 업체(B·C…) |
| 절대 안 바꿈 | 이미 고른 적용 업체 · 가격정책표 반영(자동 반영 없음) · (노션) 사용량·개당/1회·제조 단가 포함·메모 |
| 같은 것 다시 | 몇 번 돌려도 같은 결과 · 바뀐 것 없으면 저장 안 함 |
| 노션에서 사라짐 | 지우지 않고 '노션에서 삭제됨' 표시 |
| 기존 값 줄 | 처음 넣은 '완제품 매입(가격정책표 기존 값)' 줄이 있으면 품목 화면에 안내 + [그 줄 빼기] (두 번 더해지지 않게 · 사람이 판단) |
| 기록 | `cost-names/_notion.runs`(최근 30번) · 바뀐 카드 이력 · 연결 기억 `lineLinks`·`keyLinks`·`links` · 무시 `ignore` · 공급사 정보 `suppliers` |
| 보는 사람 | 업체 실명·견적서·노션 주소·공급사 정보 = `cost-names`(마스터·경영 열람만) · 카드엔 가칭 — 보안 규칙 변경 없음 |
