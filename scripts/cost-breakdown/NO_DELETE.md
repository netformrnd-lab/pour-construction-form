# 지우지 않기 — 삭제 = 숨김 + 되살리기 (2026-11-26 송희님 "올려. 단, 데이터 영구 삭제되지 않도록")

화면에는 '삭제·빼기·휴지통'으로 보이지만 실제 데이터는 남기고(누가·언제 기록) 되살릴 수 있게 함.
덮어쓰기(가져오기·반영)도 바뀌기 전 값을 남겨 되돌릴 수 있게 함. 서버 규칙으로도 문서 지우기를 막음.

## 1. 분해원가 (pourstore-cost.html)

| 무엇 | 예전 | 지금 |
|---|---|---|
| 품목 카드 [휴지통] | 숨김(deleted) · 요약(cost-ref/cards)에서는 지움 | 숨김 그대로 · 요약에도 `del` 표시로 남김 · 🗑 휴지통에서 되살리기 |
| 구성요소 줄 ✕ · 업체 A/B/C ✕ | 저장하면 사라짐(실제 업체 이름·견적서 목록도) | 저장할 때 카드 안 **'뺀 것'**(bin: 무엇·누가·언제·이유) + 실제 이름은 `cost-names.bin` → '이력·뺀 것' 탭 [되살리기] |
| 판매 국가 [이 나라 빼기] · 나라 줄 ✕ · 일정 단계 ✕ · 3팀 항목 ✕ | 저장하면 사라짐 | '뺀 것'에 남음 → [되살리기] |
| 나라 탭에서 공통 줄 ✕ | 그 나라에서만 빼기 표시 + 되돌리기 | 그대로 |
| 사진 바꾸기·빼기 (완제품·줄·업체) | 옛 사진 사라짐 · 원본 30일 뒤 삭제 | 옛 사진 '뺀 것'(작은 그림) + 이력 보관함 → [되살리기] · 원본은 파일 보관에 그대로 |
| 견적서 파일 [빼기] | '뺀 파일' 30일 → 목록에서 사라짐 · 파일 30일 뒤 삭제 | '뺀 파일' 기한 없음 → [되살리기] · 파일 그대로 |
| 견적서 링크 [빼기] | 목록에서 지움 | '뺀 파일'로 남음 |
| 노션에서 사라진 견적 | '노션에서 삭제됨' 표시 | 그대로 (지우지 않음) |
| 노션 '연결 필요' [무시] | 그 줄 내용 지움 | '무시한 줄'로 옮겨 남김 → [되살리기] |
| 저장(덮어쓰기) — 화면 저장 · 📥 엑셀 올리기 · 📋 줄 목록 · 노션 동기화 · 되돌리기 | 이력 한 줄만 | 바뀌기 전 카드 통째로 **이력 보관함**(`cost-cards/{id}/versions` · 실제 이름 `cost-names/{id}/versions`) → '이력·뺀 것' 탭 [이 변경 전으로] → [저장] |
| [가격정책표에 반영] | 원가 이력·활동 기록에 전→후 | + 카드 이력 [가격정책표 원가 되돌리기] (원가 이력·활동 기록에 '되돌림') |
| ⚙ 일정 설정 저장 | 덮어씀 | '이전 설정'에 남김 → [불러오기] |
| 카드 이력 100건 넘음 | 오래된 줄 밀려남 | 이력 보관함에 전부 남음 (📚 이력 보관함 전체 보기) |

고친 문제(같이 찾음): 📥 엑셀 올리기가 같은 카드를 고칠 때 판매 국가·일정·사진을 비우던 것 · 노션·줄 목록이 나라 줄의 업체 실명을 빠뜨릴 수 있던 것 · 노션·줄 목록이 새 카드를 만들 때 같은 열쇠의 휴지통 카드를 덮어쓸 수 있던 것 · 줄을 빼거나 더하면 이력에 '사진 바뀜'이 잘못 뜨던 것.

## 2. 가격·마진 대시보드 (pourstore-pricing-dashboard.html)

| 무엇 | 예전 | 지금 |
|---|---|---|
| 제품 휴지통 · 채널 휴지통 | 숨김 + 되살리기 (누가·언제) | 그대로 |
| 제조사 빼기·삭제 | 꺼짐 표시(off) | 그대로 |
| 바코드 지우기·다른 번호로 바꾸기 (칸·바코드 창·제품 수정 창·팀원 화면) | 번호 칸을 지움 | 지운·바뀐 번호를 `prod-barcode-st.map[제품].gone`에 기록(누가·언제) → 데이터 관리 › 휴지통 · 바코드 창 [되살리기] · 기록을 못 남기면 번호도 안 바꿈 |
| 바코드 상태 비우기 | 칸 통째로 지움 | 값만 비움 (지운 번호 기록 유지) |
| 원가 보여 주기 끔 | cost-private 문서 지움 | '끔' 표시(보는 사람만 비움 · 이력 그대로) · 다시 켜면 같은 문서 |
| 행사 지우기 | 새 화면 = 휴지통 표시 · 옛 코드(단추 없음)에 문서 지우기 | 옛 코드도 휴지통 표시로 |
| 판매 엑셀 되돌리기 | 그날 문서에서 줄을 뺌 | 빼는 줄을 묶음 기록(`sales-orders/batch-…`.undoneRows)에 통째로 남김 |
| 개정안 반려·취소 | 내용 비움 | 비우기 전 `product-meta/pricing-draft-bin`에 통째로 보관 (되살리기 화면은 아직 없음) |
| 고정지출 삭제 (브라우저 기억) | 목록에서 지움 | 숨김 + '지운 항목' [되살리기] |
| 제품명·규격 바꾸기 | 값 옮기기 | 그대로 + 분해원가 연결 바꿀 때 이력 보관함 |
| 활동 기록 · 원가 이력 | 지우기 금지 | 그대로 |

남겨 둔 것(데이터 삭제가 아님): 팀원 빼기(계정 권한 — 실제로 빼야 함 · 활동 기록에 남음) · '원본 데이터로 복원'(이 브라우저 기억만 비움 · 서버 데이터 그대로) · 견적 담기 비우기(임시 장바구니) · 직접 등록 온라인 상품(보안 구역 · 이 브라우저 기억) · 유통기한 주문 기록·그로홈 매출(다른 데이터베이스)

## 3. 소싱 원장 (Sourcing/registry.html · 같은 제품 원장)
- [삭제] = 문서 지우기였음 → 가격대시보드와 같은 휴지통(product-meta/prod-deleted)으로 · 목록 아래 '🗑 휴지통' 줄 [되살리기]

## 4. 파일 보관 서버 (functions/api/cost-files · Cloudflare KV)
- 휴지통 = 표시만(`trash/<열쇠>` 작은 값 + 누가·언제) · 파일은 그 자리 그대로 · **기한 없음**(자동 삭제 설정 없음) · **지우기 동작 없음**(KV 지우기 호출·영구 삭제 주소 없음)
- 되살리기 = 표시 풀기(표시도 지우지 않고 '되살림'으로 바꿈) · 용량: 휴지통 파일도 쓴 용량에 들어감 · 80% 경고 그대로
- 시험 `node files_test.mjs` 27가지 — 가짜 KV 의 지우기를 부르면 바로 실패하게 해 둠

## 5. 보안 규칙 (pourstore.rules) — 문서 지우기(delete) 금지
- 분해원가: cost-cards · cost-names · cost-ref + 이력 보관함(versions: 더하기만 · 고치기·지우기 없음)
- 지금 어느 화면도 문서를 지우지 않는 자리: product-meta · promotions · mkt-links · mkt-perf · team-catalog · sales-orders · config/seckey
- 아직 못 막는 자리: products-added(main 소싱 원장이 지우기를 씀) · cost-private(main 대시보드 '원가 보여 주기 끔'이 지우기를 씀) → 이 브랜치 화면은 지우지 않게 바꿈 · 병합·배포 뒤 옛 화면이 없어지면 막기 제안
- 이미 막혀 있던 자리: channels · products · config/calc · config/secure · config/access · cost-log · dashboard-activity

## 6. 시험 (가짜 데이터 · 에뮬레이터 · 로컬 Cloudflare)
- 분해원가: 줄·업체 빼기 → 뺀 것(실명 포함) → 되살리기 · 판매 국가 빼기 → 되살리기 · 처음 값으로 되돌리기 · 반영 → 되돌리기(원가 이력·활동 기록) · 휴지통 요약 · 마스터도 문서 지우기 거절 · 노션 동기화 이력 보관함 · 무시 → 되살리기 · 일정 설정 이전 값 · 엑셀 다시 올리기에 판매 국가 그대로 · 375px
- 대시보드: 바코드 지우기·바꾸기 → 기록 → 휴지통 → 되살리기 · 원가 보여 주기 끔 = 문서 남음 · 이름 바꾸기
- 파일 보관: 견적서 빼기 → 휴지통 표시(파일 그대로) → 되살리기 · 노션 복사
