## 3. 권한 (규칙 에뮬레이터 · KV 서버 시험)
- 분해원가 카드: 마스터 읽기·쓰기 · 부마스터·경영 열람 읽기만 · 열람·팀원(권한 무관)·비로그인 막힘
- 업체 실명·업체 품명·견적서 목록·공급업체/제조사 실명 표·가칭표: 마스터 읽기·쓰기 · 경영 열람 읽기만 · 부마스터·열람·팀원·비로그인 막힘
- 견적서 파일(KV): 마스터 올리기·지우기 · 경영 열람 보기 · 그 밖 막힘 / 사진 원본(KV): 마스터 올리기 · 부마스터·경영 열람 보기 · 그 밖 막힘 (팀원은 권한과 상관없이 막힘)
- 바코드 상태(product-meta/prod-barcode-st): 마스터·허용목록(열람·부마스터) 읽기·쓰기 · 경영 열람 막힘(허용목록이 아니면)
- main 규칙만 게시돼 있으면 분해원가 자리는 마스터도 막힘 → 이 브랜치 pourstore.rules 를 게시해야 분해원가가 동작
- **2026-11-26 송희님 1A 반영(pourstore.rules)**: 팀원 모두 바코드 상태 읽기 · '바코드 고치기' 권한 팀원만 상태 고치기(map 칸만 · 다른 칸 막힘)

```
      allow read: if isTeam() && doc in ['promo-types', 'sales-map', 'prod-code', 'prod-barcode', 'prod-barcode-st'];
      allow create: if isTeam() && doc == 'prod-barcode-st' && hasPerm('barcode')
        && request.resource.data.keys().hasOnly(['map', 'updatedAt', 'updatedBy']);
      allow update: if isTeam() && doc == 'prod-barcode-st' && hasPerm('barcode')
        && request.resource.data.diff(resource.data).affectedKeys().hasOnly(['map', 'updatedAt', 'updatedBy']);
```
- 규칙 시험(에뮬레이터 · 9개 역할 × 9자리): 팀원(바코드) 상태 읽기○ 쓰기○ · 팀원(권한 없음·제품 등록·원가) 읽기○ 쓰기✕ · 그 밖 자리는 반영 전과 같음
- 기존 자리 12곳(채널·제품·원가·업체단가·자체상품코드·바코드 번호·개정안·팀원 단가표·계정·활동·원가 이력) × 9개 역할: main 규칙과 한 칸도 다르지 않음
- 화면(375px): 팀 단가표 번호 옆 상태 꼬리표 · 번호나 [바코드 고치기]를 누르면 관리자와 같은 바코드 창 · 권한 없는 팀원은 보기만(그림·SVG/PNG 받기는 됨) · 억지로 저장하면 서버가 막음
